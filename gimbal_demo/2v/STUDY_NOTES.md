# 附送资料研读结论

资料包共盘点到 1148 个文件：25 份 PDF、16 个 MP4、13 个 TXT、3 个 Markdown、197 个 C/H 源文件，以及驱动、固件、工程索引/编译产物、压缩包、DWG/STP/PNG 等。控制设计主要依据最新的两份 2026-07 手册和已展开/压缩工程中的位置、速度与绘图例程；安装、驱动、原理图和 K230 支架资料用于核对电气与机械边界。

## 直接影响代码的结论

- 云台级联默认使用 ID 1（底部 yaw/X）和 ID 2（上部 pitch/Y）。
- 串口为 TTL 3.3V、115200-8-N-1；帧头 `0x7A`、帧尾 `0x7B`，BCC 是校验位之前所有字节逐字节异或。
- 总线上每个完整帧之间至少间隔 1ms；代码使用 2ms。
- 推荐控制频率 100Hz，最大 200Hz。K230 示例取 50Hz，为推理留出余量。
- 频繁改变目标位置时，应采用多圈绝对位置直通模式 `0x0003`，而不是带 T 型规划的 `0x0001`。
- 多圈位置值是有符号 32 位大端整数，单位 0.1°；反馈总角度同样是有符号 32 位、0.1°。
- 电机上电后先等待约 1.5s，再按“使能 -> 模式 -> 速度 -> 位置”顺序控制。
- 为避免启动瞬间跳到电机上电零点，先读取两轴当前总角度，把当前物理姿态建立为软件零点。
- 资料中的 STM32F4 绘图例程也采用直通位置模式、软件零点、周期反馈、反馈超时与总线串行调度，和本 demo 的结构一致。

## 硬件与机械边界

- 电机主电源 8~15V，推荐 3S；额定电流约 0.4A，最大工作/堵转电流约 1.5A。
- 电机最大 1000RPM、最小 1RPM，14-bit 角度分辨率；多圈位置指令最小单位 0.1°。
- 所有接口禁止热插拔，电源反接可能永久损坏驱动板。
- 安装资料要求电机支架使用 M2.5x5 沉头螺丝；超过 5mm 可能锁坏电机。
- 随货手册给出的建议负载不超过 100g，且重心应尽量位于电机中心。
- 关于滑环最大电流，云台手册不同页存在 1A 与 1.5A 两种表述。工程上应按更保守的 1A 设计，并实测 K230 峰值电流；必要时让滑环只传信号、另行可靠供电。

## 资料中的易混淆点

- 单电机手册写默认 ID 为 2，但成套双轴云台的快速协议和例程明确使用 X=1、Y=2。本 demo 按成套云台配置；若反馈超时，应先断开级联并用上位机逐台核对 ID。
- 最新手册更新记录提到曾修正协议 ID，因此没有沿用旧视频或旧版手册中的地址示例。
- “Y 轴 120°死角”在需求中没有给出死角中心。本 demo 默认死角中心位于逻辑 180°（后方），形成连续安全区间 `-120°~+120°`；再加 2°边界后实际为 `-118°~+118°`。安装零位不同必须修改死角中心或重新建立软件零点。
- 视觉闭环只消费检测框中心。目标检测、目标 ID 保持、相机内参/畸变、相机与两轴的外参及运动提前量属于后续标定和算法层。
