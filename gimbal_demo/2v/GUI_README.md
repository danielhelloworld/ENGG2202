# F32C 双轴控制 GUI

## 启动

在 VS Code 终端进入本目录：

```powershell
python -m pip install -r requirements.txt
python gimbal_gui.py
```

没有连接硬件时，可以先运行模拟模式检查界面：

```powershell
python gimbal_gui.py --demo
```

## 实机操作顺序

1. 固定云台，暂时拆除危险或贵重负载。
2. 断电完成 USB-TTL 与云台接线，确认 3.3V TTL、TX/RX 交叉、信号共地。
3. 把相机调整为垂直地面的位置。连接时程序会把这一物理姿态记录为 Y 轴软件 `0°`。
4. 给电机主回路供电，在 GUI 选择对应 COM 口。初次测试建议速度 10～20 RPM、加速度 50～100。
5. 点击“连接并使能”。程序自动选择“多圈位置 T 型轨迹”，设置速度和加速度，并读取两个电机的总角度作为软件零点。
6. 等待实时 X/Y 相对角度出现，再用滑块或数值输入改变目标。
7. 点击“电机失能”只关闭电机扭矩，不关闭串口；实时位置仍会持续更新。点击“电机使能”可恢复控制，原软件零点保持不变。
8. 点击“断开串口”或关闭窗口时，程序会先失能两台电机再关闭串口。

## 平滑运动与停止震荡

GUI 使用厂家推荐的“多圈位置 T 型轨迹模式”，而不是位置直通模式。速度和加速度可以在连接后修改：

- 速度越高，到达目标越快，但大负载更容易出现超调；
- 加速度决定启动和停止冲量。轨迹不平滑或停止冲击大时，先降低加速度；
- X 轴 GUI 指令范围为 `-360°～+360°`，通过多圈绝对角度协议发送；
- Y 轴仍有相对软件零点 `-100°～+100°` 的驱动硬限制。

## 速度环 PID 调试

厂家资料给出的速度环 PID 范围为 `0～256`，经验范围为 KP `5～50`、KI `5～100`。GUI 不会在连接时自动覆盖电机 PID：

1. 选择 X 或 Y 轴；
2. 从较小的 KP/KI 开始，点击“临时应用”；
3. 每次只小幅增加一个参数并观察到点超调、回摆和高频振动；
4. 效果确认后再使用“应用并掉电保存”。保存操作有二次确认。

负载下到点超调或往回修正过大时，可小幅增加速度环 KP，再视情况增加 KI。参数过大会引起空载高频振动。位置环 PID 按厂家说明通常不需要修改，因此 GUI 只开放速度环。

## 安全层级

Y 轴允许范围固定为相对软件零点 `-100°～+100°`：

1. Y 滑块只显示该范围；
2. 数值输入会拒绝区间外数值；
3. GUI 到后台线程的接口会再次检查；
4. 基础驱动在生成任何位置帧之前进行最终检查。

因此越位命令不会写入串口。X 轴的 `-360°～+360°` 是 GUI 操作范围；F32C 多圈协议本身支持更大的累计角度。

## 零点注意事项

限制是相对于每次连接时捕获的软件零点计算的。连接前相机必须处于“垂直于地面”的真实零位；否则 ±100° 范围会相对错误的物理姿态偏移。

GUI 显示的“电机总角度”是控制器反馈的原始累计角度参考，不要求它本身等于 `0.0°`；程序把这个读取值映射为界面中的相对 `0.0°`。重新连接后会重新读取，软件零点不写入电机 Flash。
