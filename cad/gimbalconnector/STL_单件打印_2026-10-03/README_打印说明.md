# 单件 STL 打印包

所有文件另存于本目录，原模型、已有 STL、Fusion 文件及项目说明均未修改。每个 STL 只包含一个独立且封闭的连通零件，以 mm 为单位；仅平移到 XY 居中、最低点 Z=0，没有缩放或旋转。导入切片软件后可分别旋转、排列和设置数量。最低点归零不代表已经选择最佳打印朝向，底座的下伸柱和四角固定立边仍需检查支撑。

## 目录选择

| 目录 | 用途 | STL 数量 |
|---|---|---|
| `01_V3_USB优化版/` | 外移、预留 USB 空间的当前版本 | 5 个正式部件 + 4 个试件 |
| `02_V2_原位置加强版/` | 保持原位置，增加底柱和侧向热铆销 | 5 个正式部件 + 4 个试件 |
| `03_V2_原版/` | 最初确认长边对齐的版本 | 4 个正式部件 + 4 个试件 |
| `04_V1_历史方向试作_未采用/` | 仅为完整保留早期单件导出，方向未采用 | 4 个正式部件 + 4 个试件 |

共 34 个单件 STL。建议从前三个目录中选择一版使用；V1 仅供历史参考。每版的间隙试装件单独放在 `试装件/` 中。

## 零件选择与数量

| 文件前缀 | 零件 | 打印数量 |
|---|---|---|
| `01_` | 摩擦快拆底座，一体底部热铆柱固定 | 1，与 `02_` 二选一 |
| `02_` | 摩擦快拆底座，M2 螺丝固定 | 1，与 `01_` 二选一 |
| `03_` | 相机快装板，中心 1/4 英寸金属螺丝固定 | 1，与 `04_` 二选一 |
| `04_` | 相机快装板，保留中心孔并增加四角螺丝固定立边 | 1，与 `03_` 二选一 |
| `05_` | 独立侧向热铆销，文件只有一颗 | **2 颗**，加强版和 USB 版使用 |

快拆板与底座之间通过打印燕尾和弹性肋摩擦固定。`01_`/`02_` 是底座与云台的两种固定方式，`03_`/`04_` 是相机与快装板的两种固定方式。

USB 版热铆组合示例：在 `01_V3_USB优化版/` 导入 `01_` 底座、`03_` 或 `04_` 相机板，再导入 `05_` 铆销并把数量设置为 2。M2 底座也保留侧向销孔。中心 1/4 英寸螺丝、M2 螺丝及相机四角螺丝为金属紧固件，不属于打印零件。

**底座底部热铆柱与底座一体成型，四角固定立边与相机板一体成型，因此分别保留在对应单件 STL 中。** 独立侧向热铆销已单独导出。将一体结构拆成分离零件需要增加连接结构，属于新的设计改动，本次导出保持原设计。

## 检查记录

`打印清单.csv` 列出每个文件的数量、用途、尺寸及来源。`单件网格验证.json` 记录每个零件的单一连通性、封闭性、退化面、尺寸及体积保持检查，并保存已有项目文件的 SHA-256 校验结果。`单件STL打印包.zip` 包含各版单件 STL、说明和检查记录，解压后使用。

打印朝向、支撑、螺丝长度与热铆装配步骤可参阅原项目 `README_快拆转接台.md` 和 `README_加强版与USB优化.md`。实际摩擦保持力与热铆强度仍需打印试装。
