# 固定角度抗扰保持

目标：使能保持时手动施力把轴转开，撤力后仍由 F32C 的位置闭环回到原保持角度；不能把外力造成的位置当作新平衡点。

`hold-range-v22` 的参考更新规则（v21 引入，v22 放宽误触发门限）：

- 正常范围内手动 ARM：锁定使能时预装给驱动的当前位置。
- HOME 完成：锁定最后下发的零位。
- 目标角度运动完成、普通手动制动完成：锁定最终下发的落点。
- 主动摇杆、跟踪或新的角度运动会释放旧参考，完成后建立新参考。
- 外力、编码器角度变化、短暂反馈降级和恢复都不重新定义保持参考。DISARM 与故障清除参考，不自动反复使能。

保持期间不根据反馈位置重写目标，不叠加软件“推力”增益，仍由驱动已有位置/速度闭环出力。网页显示 `锁定保持参考`，状态接口提供 `hold_target_deg / hold_fixed_active / hold_error_deg`，telemetry 也记录保持参考。参考角度不变不等于电机必然有足够扭矩；当前既没有电流/力矩遥测，也没有修改驱动 PI 或电流配置。

短时人工扰动不套用普通连续运动的 1.8 秒无进展检查。v21 的 yaw 12°／pitch 9°相对偏差围栏已删除：一次实测 pitch 被推到 14.5°，被这个围栏打断回位，因此 v21 的实机抗扰测试失败。v22 依据原正常工作限位检查，而不单凭离保持参考超过 9°失能。保持或近零回零稳定阶段的大幅反馈变化，须连续两个新鲜且一致的有效反馈复核；首个孤立异常仍只暂停，不更新目标。工作限位、初始限位外向外偏移、主动运动的跳变检查、真实失联和明确 DISARM 保留。

偏差超过 2°且连续 8 秒没有至少 0.2°回位进展，仍报持续无回位进展。软件不能可靠区分手动施力、卡阻和力矩不足，不以此承诺任意力度或任意持续时间都能回位。正常工作限位约束指令，外力实际推过边界的短暂反馈仍按原有反馈容差和复核处理，不能把软件限位当作机械止挡。

首次实机人工测试：等待 `HOME_HOLD` 且网页显示锁定保持参考，先推一个轴偏移约 2～3°，保持不到两秒后松手，观察目标参考是否不变、是否回位、是否仍使能，再决定是否需要调整驱动增益。目标角度测试仍须独立点击开始，不自动执行。

## 验证边界

- 215 项本机跟踪测试通过。新增合成扰动保持超过旧 1.8 秒窗口、原参考不变、模拟驱动闭环撤力后回位、短反馈暂停不重定目标、持续卡阻仍失能、工作限位仍检查、人工控制释放旧参考、HOME 锁定零位。
- 108 项独立电机 demo 测试和两套网页事件测试通过。独立 demo 的静止检查语义保留。
- 实机 v21 已启动并从当前位置回零，读取 `HOME_HOLD / armed=true / fault=null`，目标 0°／0°；启动记录 `../../research/motion_jitter_20261105/v21_startup.json`。
- v22 用户实测确认“保持使能，并回到原角度”。随后读取 HOME_HOLD、armed=true、fault=null、实际 yaw −0.2°／pitch 0.0°、保持目标 0°／0°。完整状态和 telemetry 保存在 `v22_hand_test_state.json / v22_hand_test_telemetry.json`，摘要 `v22_hand_test_summary.json`。这证明本次操作的回位结果，不代表已测出最大抗扰力矩；没有力传感器。

## 重新检查补充

保存零点模式下，“重新检查”由 UART worker 查询每轴新的机械角度并重建参考。无需失能偏心轴静止，不查询速度来强制为零，不修改零点、不自动回零、不自动使能。缺一轴、旧缓存或无效反馈仍不得通过。上一次 fault/失能记录保留在 `recheck_diagnostic.previous`，失败立即标为 `FAULT / FAILED`。

v19.1 恢复连接后实际读到：角度测试状态仍为 IDLE，回零时 pitch 被角度跳变检测拒绝（2.0°→−10.3°），连续 500ms 后失能。记录在 `v19_1_reconnected_fault.json` 与 `v19_1_reconnected_telemetry.json`。这是读取到的一个回零故障，不证明它就是此前网络连接失去响应的根因。
