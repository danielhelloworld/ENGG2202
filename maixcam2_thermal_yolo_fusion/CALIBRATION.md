# 多距离双光校准

适用于已固定安装的 MaixCAM2 + Thermal160。用户安装位置为热像相对可见光镜头向右 5 cm、向下 5 cm，轴向偏移未知；配置中轴向 0 只作安装记录，不参与像素变换。精确映射必须从两幅图的对应点测量。

本功能在 **[main.py](main.py)** 中运行；`hardware_probe.py` 是限时诊断入口，不提供交互校准。请在 MaixVision 打开 main.py，点击“运行当前文件”，然后在**设备触摸屏**上操作。MaixVision 预览可用来观察；没有实现将电脑预览上的鼠标点击转发成触摸。

点校准和每距离手动缩放继续由 **SAVE** 写入设备的 `alignment.json`。新增的 **HOT** 只在当前运行中选择一个热块跟踪，不改动或覆盖已保存的校准参数；进入CAL时会清除跟踪选择。跟踪前先确认热像正常刷新并选对DIST档位，详见 [应用说明](README.md#单点热块跟踪)。

## 为什么需要不同距离的配置

两幅图视场不一致、镜头有约 7.1 cm 的横向/纵向合成间距，近物与远物的相对位置不同。每个档位独立估计一个平面透视映射，补偿不同视场对应的比例、偏移、旋转及透视差异。仅凭 5 cm 偏移，缺少镜头内参、方向与目标距离，不能计算准确像素偏移。

默认距离档位是 **0.5 / 1 / 2 / 3 / 5 米**，尚未包含任何实测校准值。可在 CONFIG 修改 `calibration_distances_m` 和 `calibration_distance_m`。距离按可见光镜头到靶平面估计，单位米；记录标称距离的同时保持安装角度和主工作平面一致。

运行时按 **DIST** 切换，画面显示当前距离及检查误差。程序没有深度传感器，不会自动测距、按类别估计距离或在两张矩阵之间插值。没有校准的档位显示 `NO POINT CAL` 并退回粗略矩形叠加，不会默默套用另一距离的矩阵。

## 准备目标

1. 固定两个相机的相对位置、焦距及朝向。镜头的光心间距可能与外壳边缘的 5 cm 不同，但点对校准会直接测量实际映射。
2. 在选定距离放置一块平面板，设置至少 **8 个**在可见光和热像里都能辨认的标记，推荐 10～12 个。可以用固定在板面、可见轮廓清楚且温度有对比的温热小圆片，选相同物理中心。普通打印黑白格不保证有热像对比。
3. 标记要覆盖两幅图的**共同视场**，包括四周和中间；全部位于同一平面，避免只在中心一小块布点。留出至少两个不同位置的标记专门检查，不参与拟合。
4. 保持板与相机静止，等待热像正常更新。近距离优先布更多距离档位。热斑晕染边界未必等于可见光边界，选中心通常更容易重复。

## 屏幕操作

1. 按 **DIST** 选距离，按 **CAL** 进入校准界面。
2. 确认目标静止，按 **FREEZE** 冻结这一组可见光/热像。若热像过期或时间差过大，会拒绝冻结。两路时间来自主机接收时间，仍需静止目标。
3. 画面显示 **RGB**：点一个标记中心；界面切到 **THERMAL**：点同一个标记中心。这样完成一组点对。热像会自动按配置翻转，内部再还原到原始热像坐标。
4. 重复至少 **6 组**，推荐 **8～12 组**；按 **UNDO** 撤销上一处未配对点或上一组。使用的是冻结图，不要移动后另找目标。**FREEZE 会清空当前未应用的点对并重新拍一组。**
5. 按 **FIT**。RANSAC 剔除明显错配；至少保留 6 个且不少于 75% 的点对，并检查分布面积、矩阵有效性。失败信息会显示在底部。
6. 进入 **CHECK** 阶段后，在这对冻结图中选 **至少 2 组新的标记**，不能复用拟合点，要分散在不同位置。若有明显不均匀畸变，可增加边缘和中部检查点。
7. 按 **APPLY**。独立检查点的最大误差默认必须不超过 **6 个原始可见光输入像素**，才会启用该距离的映射；不是 6 个热像像素，也不是 6 个屏幕像素。失败时可 UNDO 重选，或 FREEZE 重做。
8. 回到融合画面后按 **SAVE**，再用新的真实目标检查叠加边缘及框内温度的对应位置。更换距离后重复上述过程。

`CANCEL` 放弃当前未应用的校准，保留旧配置；`APPLY` 先应用到内存，`SAVE` 才持久保存。点校准后也可以按 ALIGN 微调覆盖范围；界面会改为 MANUAL TUNE，原先的检查误差不再代表微调后的映射。

## 广角画面中的热像大小：前后缩放

热像层应只覆盖可见光中相应的区域。新安装且未载入保存数据时，默认覆盖中间宽高各50%的区域，仅作为手动调整起点，**不是两个镜头的实测视场比例**。已有JSON或点校准会保留原来的几何，不会被这个默认值覆盖。

在设备屏幕按 **DIST → ALIGN**，会显示青色覆盖边框、中心十字和两排按钮：

| 按钮 | 操作 |
|---|---|
| FAR | 推远：以热像中心为基准等比例缩小，让热像落在广角画面的较小区域 |
| NEAR | 拉近：以热像中心为基准等比例放大 |
| LEFT / RIGHT / UP / DOWN | 移动热像覆盖位置 |
| W- / W+ / H- / H+ | 单独调整宽高，补偿横纵覆盖比例不同；优先先用FAR/NEAR保持比例 |
| FINE | 切换细调：缩放每次1%、移动每次画幅0.2%；粗调为5%、1% |
| RESET | 撤销当前距离档位的手动缩放/移动，恢复该档点校准或默认粗略矩形 |
| SAVE | 将所有距离的点校准和手动调整共同保存 |

建议先FAR缩到大致视场，再移动中心，最后细调。透明度可用ALPHA调整。缩放以热像中心为轴，保持位置稳定；覆盖范围之外保留可见光，不用热像填满。框内温度同步使用调整后的原始热像像素投影，不会只移颜色而忘记移动测温位置。缩放不生成新的热像细节。

这里的“前/后”是**交互缩放**，不是目标距离或镜头轴向偏移的测量，没有厘米刻度。DIST记录工作距离档位，FAR/NEAR只调整此档的图像覆盖大小。若要用真实镜头前后间距计算投影，还需要两镜头内参、姿态及目标深度；当前只记录已知右移/下移5cm，不凭空估计轴向距离。

每个档位的手动调整独立保存，切换DIST不会污染其他档。已校准的基础矩阵始终保留；RESET可恢复并重新显示基础检查误差。重新CAL并APPLY会清掉**当前档位**的旧手动调整，避免将旧补偿重复叠到新校准上。

## 保存与复用

- 默认保存设备文件：`/root/thermal_yolo_fusion/alignment.json`，包含全部距离档位。SAVE 会创建目录并原子替换 JSON，避免 MaixVision 的临时运行目录变化导致配置丢失。
- 可通过 MaixVision 设备文件管理器下载该文件作为备份。日志同时打印 `CONFIG['calibration_profiles'] = {...}`，可在电脑上的 main.py 中 CONFIG 字典结束后添加这一赋值，以便随单文件上传。板上同名有效档位优先于内嵌配置。
- 若使用手动前后缩放，日志也打印 `CONFIG['manual_adjustments'] = {...}`；备份到代码时一并复制。当前JSON为schema4，含相机帧率；缺少该字段的旧文件会被拒绝并提示重新校准。
- 修改模型输入尺寸或热像翻转会使旧配置被拒绝。更换镜头、移动安装、改变相机裁切/缩放/方向后，即使分辨率没变，也需要重新校准；软件不能自动检测所有光学变化。
- 独立帧率版本采用schema4并记录camera_fps；切换帧率或旧配置没有帧率字段时需重新校准。详见[性能说明](PERFORMANCE.md)。
- `calibration_max_error_px` 是允许的点击/检查误差，不是温度精度；不要为了获得 PASS 随意放宽。

## 能达到的范围

单档映射适用于该距离附近、姿态相近的平面。多档解决的是**切换主要工作距离**的问题；同一画面内 0.5 米前景与 5 米背景不能靠一张映射同时完全对齐。明显深度变化、遮挡和两镜头互不可见区域需要额外深度信息或更完整的双目标定。此版本不包含镜头畸变参数估计；若中心对齐、边缘仍系统性错位，需增加内参/畸变标定，不能靠多加几个距离自动消除。

UI 的 `check Npx` 是所选独立检查点上的误差，不是全图精度保证。160×120 热像分辨率、手指点选误差、同步误差及目标深度也会限制最终精度。屏幕与 RTSP 使用相同校准后的最终图；YOLO 框测温仍取相同映射下的**原始热像像素**，不会对伪彩插值结果测温。

算法依据：[OpenCV 平面单应性说明](https://docs.opencv.org/4.x/d9/dab/tutorial_homography.html)、[findHomography 与相机投影模型](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)。

## 已验证与尚待实测

新增 11 项本机测试：已知透视矩阵恢复、错配剔除、退化/非法矩阵拒绝、独立点误差门槛、翻转与 ROI 对应、等比留边、多距离保存重载、过期帧拒绝、完整点选流程及取消。测试输入是已知几何的合成数据，不能证明你当前安装的实机精度。设备上仍需要按上述步骤采点，再验证新目标的重合效果。

前后缩放另增加7项测试，覆盖中心/比例不变、缩放后ROI对应、逐距离保存重载、默认窄画幅外像素不变、细调与边界限制、新校准清除旧调整及非法配置拒绝；校准类合计18项，加融合/RTSP 18项，共36项通过。
