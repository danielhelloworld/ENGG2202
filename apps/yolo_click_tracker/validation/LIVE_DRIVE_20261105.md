# 2026-11-05 双轴驱动响应实测

实际 MaixCAM2 + F32C 电机，运行本地 `hold-drive-v16`。本轮按用户要求执行回正和驱动响应校准，现有 PI 未知，未改 PI、机械零点或 Flash。厂家上位机留待取得已知 PI 基线后使用。

## 修正与部署

- 修复回零剩余误差很小时的“requested movement has no physical progress”误判。原故障的 yaw 约 0.8°，低于位置误差保护阈值，不应单凭规划器仍有回零请求判为卡阻；较大误差无进展、反向和越界保护继续执行。
- 启动采用已保存单圈机械零点，不再要求偏心负载在失能时先静止，再计算参考。仍读取合法实时反馈，以确定向内方向和约束每次目标。
- 回零到位容差 1°，稳定时间 0.25 秒；仍下发 0°目标，随后继续使能收敛。实测最终约 yaw −0.1°、pitch 0°，没有将容差写为新零点。
- 保留机械限位 yaw −150°～150°、pitch −100°～30°。限位外只允许沿当前角向零点的小步恢复；正常目标不扩大限位。
- 方向保持 `motor_signs=(1,1)`、`joystick_signs=(-1,-1)`。

切换前自动审批曾拒绝停止仍可能保持限位外负载的旧程序。随后实时 API 和屏幕均确认旧程序已经 DISABLED，再结束旧程序并加载新版。新版实机启动、回正和后续测试均成功。没有绕过拒绝去终止仍使能的程序。

## 实测结果

| 项目 | 实测 |
| --- | --- |
| 启动实测姿态 | yaw 5.8°、pitch 91.7°，俯仰在工作限位外 |
| 首个使能样本到 HOME_HOLD | 约 2.65 秒，包含稳定确认 |
| 小角度测试 | 两轴分别 ±0.08、±0.16、±0.30 归一化输入，12 次短脉冲 |
| 本轮角度范围 | yaw −11.8°～0°，pitch −6°～3.2° |
| 方向 | 每次正反向脉冲的机械角变化均符合配置；未改变方向符号 |
| 测试中失能／故障 | 0，测试后回零并交回 LOCAL 保持 |
| 最后 5 秒反馈峰峰值 | yaw 0°、pitch 0.1°，受编码器分辨率限制 |
| PC API 轮询 RTT 中位数 | 约 62ms，电脑链路只用于本轮测试 |

本轮手动脉冲后，从 API 松手时的反馈快照到后续稳定姿态仍有约 0.9°～4.5°变化。快照早于串口线程实际处理松手，不能将此数值直接称为固定目标过冲。PC 看到首次 0.3°角变化约需 234～313ms，包含 HTTP、应用调度、UART 与反馈采样，不是纯电机延迟。正反向和不同短脉冲行程不完全一致，暂不据此继续提高最高速度。

现有手动目标上限 240/180°每秒、跟踪 75/60°每秒、HOME 108/90°每秒均为配置上限。本次小行程没有证明这些速度全部可达到，也没有在限位附近做最大速度或制动距离认证。正常运行由板端控制，不要求 PC 持续在线。
