# F32C：偏心相机负载与模型辅助调参

新增的两个自动整定模块及操作入口见 [一键整定说明](../yolo_click_tracker/AUTOTUNE.md)。本目录 `main_web.py` 的“开始 PI 自动整定”使用填写的已知 Kp/Ki 基线，按单轴试动、评分和复测流程执行。

2026-11-04。适用 MaixCAM2 的网页摇杆 `main_web.py`。X=YAW（ID 1），Y=PITCH（ID 2）；Y 轴失能后会因相机重心偏离转轴而下垂。

## 启动与独立配置

**运行新版即会回零。** 程序检查机械反馈及限位，预装实测当前位置，先使能俯仰，再使能水平，随后回到已保存的机械 0°。到位后保持使能；首次网页或电脑连接器接管时不插入失能。先核对机械零位和运动空间，俯仰失能时支撑负载。

单文件搜索 `TUNING_CONFIG`。`startup_auto_home=False` 可恢复等待手动 `ZERO OK → ARM` 的启动方式。自动回零只在启动执行一次；取消或故障后，排查并主动重新检查，再走手动使能。机械零位、累计寄存器和 Flash 不会被自动回零修改。

| 阶段 | YAW / PITCH 目标速度上限 | 独立参数 |
| --- | --- | --- |
| `startup` 自动回零 | 24 / 16°/s | 驱动 RPM、驱动加速度、软件目标速度和加速度 |
| `manual` 手动 | 24 / 16°/s | 同上，可单独降低或改变 Y 轴 |
| `home` 日常 HOME | 10 / 8°/s | 同上，独立于启动速度 |

各组默认驱动上限仍为 5 / 5 RPM，加速度指令为 10 / 10；实际负载下的速度需要实测。启动无额外等待，回零到位确认时间为 0.2 秒。原有倒装方向、机械限位（PITCH −100°～+30°）、反馈和停止检查仍生效。启动回零与首次接管前的零位保持在板上执行；接管后按原控制心跳工作，浏览器离开控制或连接器停止会请求失能。

## 模型怎么调

电机固件运行高速 PI 闭环；MaixCAM2 记录已发送目标、实测角度、每轴采样时间、当前阶段和本程序最后发送的增益。模型用几秒到一轮测试的反馈来更新参数，不接管底层控制周期。没有文档化的 PI 读回或 ACK；历史发送值是试验标签，不能作为设备当前参数的确认。

1. 启动相机程序后，使用网页控制，或让电脑连接器接管；同一时间只用一个控制端。
2. 从未知原参数开始，先记录带相机原地保持约 5 秒。保持工况与目标相同，先看俯仰的平均角度偏差、固定目标峰峰值和反馈是否稳定。
3. 每次只测一轴，轻推小角度往返，松手后继续记录约 2 秒。对比目标轨迹相近的两轮，查看回摆、峰值偏差、稳定时间与跟踪误差。姿态会改变重力负载，至少在机械零位和实际工作俯仰姿态各检查一次。
4. 停稳后只发送一个参数的临时改动，再重复同样的输入。PI 写入可以在保持使能时完成；输入框留空的参数不写。程序不自动猜测初始 Kp/Ki，也不保存 Flash。首轮原值未知时不能承诺自动恢复该原值；临时值和厂家已保存值要分开记录。

网页的实时图是浏览器采样，导出的 JSON 保留板上采样时间和数据。记录上限 60 秒或 2400 个样本；导出本轮后再开始下一轮。编码器数据分辨率 0.1°，记录不能排除高频振动；若相机明显下垂或持续抖动，先检查安装重心、支撑及带负载保持能力。

## 电脑端连接器

电脑本地运行，URL 使用 MaixVision 显示的实际局域网地址。已有网页控制时先退出该控制会话，或让连接器在启动回零后首先接管。

```powershell
python -B MaixCam/apps/motor_joystick/feedback_bridge.py --url http://相机IP:8080
```

连接器保持约 80 ms 的控制请求周期，模型分析和数据导出不会暂停心跳。`output/feedback/latest_state.json` 约每秒更新，停止记录后会导出 `trace-*.json`。交互终端每行接收一个 JSON 命令：

```jsonl
{"action":"record_start","note":"带相机，保持零位，原参数未知"}
{"action":"record_stop"}
```

`status` 立即输出状态；`pi` 接受 `axis`（0=X / 1=Y）及 `kp`、`ki` 中要改的项；`pulse` 接受有界摇杆 `x`、`y` 和不超过 1 秒的 `seconds`，到时自动松手；`stop`、Ctrl+C 或 EOF 结束会话并请求失能。连接器没有内嵌模型服务；当前 Codex 对话可通过它读取反馈、逐轮发参数和比较结果。

## 验证与下次操作

电脑回归覆盖启动回零和取消、保持使能交接、临时单参数 PI、写入取消、反馈缺失和有界采集。模拟网页显示 `HOME_HOLD`；真实本机 HTTP 的端到端回放验证连接器在 1.45 秒无新上层指令期间保持会话，在模拟俯仰轴单改 Kp 时维持使能，并导出 116 个样本。该记录来自协议模型，不用于估计真实电机参数。

当前没有板上运行实例，未启动、连接或修改实机。下次用 MaixVision 运行本地新版 `main_web.py`，取得当前网页地址，先采集原参数下的保持与单轴短脉冲基线，再决定首轮实际增益。
